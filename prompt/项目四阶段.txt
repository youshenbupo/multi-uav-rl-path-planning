五、测试

为每个模块创建 pytest 测试。

使用 MATLAB 回归数据进行：

numpy.testing.assert_allclose

确定性基础函数优先使用：

rtol <= 1e-6
atol <= 1e-8

如果 MATLAB 与 Python 插值实现存在数值差异，可以放宽，但必须：

1. 解释差异来源；
2. 记录到 docs/known_issues.md；
3. 不能直接把容差调到很大使测试通过。
