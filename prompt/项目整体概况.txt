1. D:\yolo\multiuav\legacy_hgalo 是论文使用的 MATLAB 基准版本。
2. 默认不得直接修改 legacy_hgalo 中的文件。
3. 可以读取、分析和调用 legacy_hgalo。
4. 需要新增 MATLAB 导出或包装脚本时，优先放到新项目的 tools/matlab 目录。
5. 不要逐行机械翻译 MATLAB，而要按照功能模块重构为 Python。
6. Python 实现必须通过 MATLAB 基准数据进行回归验证。
7. 在环境评估器验证完成前，不要开始实现 MAPPO。
8. 在普通 MAPPO 能正常训练前，不要加入 GNN、分层策略或 CBF。

11. 所有代码使用清晰的英文变量名、类型注解和必要的文档字符串。

13. 所有实验配置使用 YAML，不要把关键参数散落在代码中。
14. 所有路径通过 pathlib 管理，避免在核心代码中写死绝对路径。
15. Windows 下的命令优先使用 PowerShell。
16. 训练代码后续应能迁移到 Linux GPU 服务器运行。
17. 初期不要依赖 PyTorch Geometric；预测冲突图优先使用纯 PyTorch 实现，降低 Windows 安装风险。
