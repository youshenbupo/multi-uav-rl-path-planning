目标是先证明训练管线正确。

一、算法要求

实现参数共享的 MAPPO：

- shared actor；
- centralized critic；
- decentralized execution；
- PPO clipped objective；
- GAE；
- entropy bonus；
- value loss clipping；
- gradient clipping；
- observation normalization；
- reward normalization可配置；
- action Gaussian distribution；
- deterministic evaluation。

四、必须先完成的小环境验证

先用简单无障碍 2-UAV 场景训练，目标是确认：

- reward 上升；
- 到达率上升；
- policy loss 和 value loss 数值正常；
- 不出现 NaN；

- deterministic evaluation 可运行。
